# FrateTrain

A fitness app built with [Expo](https://expo.dev) and React Native.

## Get started

1. Install dependencies

   ```bash
   npm install
   ```

2. Start the app

   ```bash
   npx expo start
   ```

Routes live in `src/app/` (file-based routing via [Expo Router](https://docs.expo.dev/router/introduction/)).
