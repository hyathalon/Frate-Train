## The coach's proposal (to compare against)
- 3–4 runs a week (Hyathlon-class running efforts count), considering the strength classes and how the knee responds.
- Periodised blocks: aerobic development, running economy, threshold, then marathon-specific endurance.
- Long-run progression is the key focus towards the marathon.
- One traditional interval session a week; intervals added to the long run after 3–4 long runs.
- Monitor the body as load increases. Flexible.

## Where the coach's program differs from the app's current rules
1. **Hyathlon taper:** the coach's taper is about 6 days (last long run with efforts 6 days out, then an easy race week). The app's rule is 8–14 days with volume down 40–60%.
2. **C race (10 km):** the coach gave a rest day + shakeout before it, and no quality session the week after. The app's rule: at most one lighter day before, and "10 km or shorter: straight back into it".
3. **Program start:** the coach starts the program as soon as the athlete is ready (here a Saturday). The app's blocks start on a Monday.

## Gaps this case found in the app
- **"No-running days" are different from "can't train" days.** She trains every day but won't run on her class mornings (Tue, Thu). Onboarding needs a "days I don't want to run" option.
- **Classes that alternate** (Mon *or* Tue, depending on the week).
- **The marathon is the real A race** but running-race goals are "coming soon", so the app can only plan the Hyathlon block for now.
