# Running Workouts — Design Guide

Read `00-training-zones.md` (5-zone model, session types) and `01-workout-design-principles.md` (purpose → norm → build/maintain → size of shift → frequency) first. This file applies the manipulators to running. **All intensities are Zone + RPE**; an athlete's own paces are only logged results or stored zone values. Method-by-method work, recovery and totals are in `05-training-methods.md`.

---

## 1. Session building blocks (Magness session types)

| Session type | Zone (RPE) | Main pillar | Purpose |
|---|---|---|---|
| Recovery / absorption | Z1 (1–4) | Fatigue Management | Absorb the last hard session; almost too easy |
| Easy ± strides or 30–60 s surges | Z2 Easy (5–6) | Aerobic Engine | Aerobic base; light FT touch; lactate clearance |
| Long run (most 60–90 min; advanced up to 90–120 min) | Z2 Steady (6–8) (optional Z3 race-pace segments) | Aerobic Engine, Durability | More fibres trained aerobically as easy fibres tire |
| Progression run | Z1/Z2 → Z3 (–Z4) | Aerobic Engine, Threshold | Broader fibre recruitment; controlled early, honest by the end |
| Aerobic threshold (marathon–half pace) | upper Z2 – low Z3 (7–8) | Aerobic Engine, Threshold | ST recruitment without high lactate; often inside the long run |
| Lactate threshold (15 km / hybrid-race pace) | Z3 (8–8.5) | Threshold | Clear and reuse lactate; often in blocks (e.g. 20 + 10 min) |
| Above threshold / critical velocity (10 km–5 km) | Z4 (8.5–9.5) | Threshold, Aerobic Engine | Fresh stimulus once LT is maximised |
| VO2max intervals (3–5 km) | upper Z4 – Z5 (9–10) | Aerobic Engine (ceiling) | 1–3 min reps, **standing** rest ≈ half the work time (a jog recovery makes it threshold work); focused blocks only |
| Speed endurance (30–90 s reps) | Z5 (9.5–10), full recovery | Aerobic Engine | Fitness: holding speed and form under high lactate; focused blocks |
| Sprint intervals / hill sprints (30 s or less) | Z5 (short), full recovery | Economy | Running economy: neural drive, mechanics, fast-twitch recruitment |
| Race-specific / compromised runs | Z3–Z4 | Durability, Fatigue Management | Running well when already fatigued; race rhythm |

Sprints of **30 s or less are for running economy**, not fitness. Once reps are longer than 30 s they become speed endurance (a fitness session).

Keep **Z1 and Z2 distinct**: Z1 (RPE 1–4 · Recovery) is **only** for recovery runs, warm-ups and cool-downs. Easy runs are RPE 5–6 (Easy); long runs are RPE 5–6 for beginner–intermediate runners and RPE 6–7 for advanced. Athlete-facing labels use RPE, not zone names (see `00` §6).

### Long run: set from the athlete's recent data
- A long run is usually **60–90 min** for most athletes; **90–120 min max** for advanced athletes. Beginners build up to this from their current longest run.
- Ask at onboarding: **"What is your longest run in the last 3 weeks?"**. Start the long run at or just below that.
- Extend in small steps from there (~5–10 min per step, with a lighter week in each block), capped by the phase and the event.
- The athlete may choose to run longer or shorter. The next 4-week block is built from what they **actually completed**, not what was planned.

### Advanced / high-volume running week
From a high-level marathon program (about 130–140 km/week). **Advanced Hyathlon athletes can reach about 70–100 km/week** using the same shape, scaled down:

| Day | Session | Effort |
|---|---|---|
| Mon | Aerobic run (~45–60 min) | RPE 5–6 · Easy |
| Tue | **Quality** (threshold / tempo) AM + second session PM | Quality RPE 8+; PM easy |
| Wed | **Medium-long run** (**12–15 km** for most Hyathlon athletes) | RPE 5–6 · Easy |
| Thu | **Quality** (track / intervals / threshold) AM + second session PM | Quality RPE 8+; PM easy |
| Fri | Aerobic or recovery run | RPE 1–4 or 5–6 |
| Sat | Recovery (absorption) run | RPE 1–4 · Recovery |
| Sun | **Long run** (most 60–90 min; advanced 90–120 min max; optional race-effort segments) | RPE 6–8 · Steady |

- **Second sessions go on quality days** (hard days hard, easy days easy). Max 2 sessions a day. **Strength gets the PM slot first.** An easy double run (30–45 min, RPE 5–6) takes the PM slot on a quality day only if there's no strength there; otherwise doubles go on other days, and only if the athlete wants them.
- Doubles only for athletes who can train twice a day and are at high volume.
- **Build weeks stay steady** rather than big waves; progress one thing at a time.
- **Medium-long run** is a session type: longer than an easy run, shorter than the long run, easy effort.
- **Taper (about 3 weeks):** about **80%**, then **60%**, then about **30%** of usual volume in race week (plus the race). **Taper by event:** **Hyathlon races: scale with volume.** Low volume (3 or fewer runs a week): about 7 days, frequency and intensity kept, session types change (shorter efforts), no big volume cut. Higher volume (4+ runs a week): **8–14 days**, volume down 40–60%, keep intensity and frequency (`09` §5). **Marathon:** by program length: 12+ weeks → 3 weeks; 6–11 weeks → 2 weeks; up to 5 weeks → race week + 1 week. **Half marathon:** under 8 weeks → 1 week (race week); 8+ weeks → 2 weeks. Rest days and optional aerobic runs appear; quality stays but shortens. **Race week:** a short race-effort session about 5 days out, an easy run with a few efforts, a short shakeout the day before, then the race.

## 2. Manipulators applied to running

### 1) Speed / intensity
- **General increase:** raise the zone of the whole session (e.g. 10×400 m @ Z3 → @ Z4), or keep the zone and look for faster logged splits.
- **Within rep:** change effort inside the rep. 600 m reps @ Z4 → 600 m progressing Z3 / Z4 / Z5 per 200 m.
- **Why:** a faster output in the same zone (same fatigue) means the athlete can now run a touch faster for the same cost.

### 2) Recovery
- **Length:** longer rest = more recovery of all systems, lets anaerobic capacity engage. Shorter rest = more aerobic; working under incomplete recovery. (VO2max reps: standing rest ≈ half the work time. A jog recovery turns it into threshold work rather than true VO2max training.)
- **Style:** standing vs moving changes blood flow and clearing/using by-products.
- **Speed of recovery:** faster float recoveries improve handling of fatigue by-products (e.g. 200 m float @ Z2 instead of a walk).
- **"Stuff" in the recovery:** a mentally demanding task (e.g. Stroop test) to keep focus high while the body recovers; or a small strength/reactive circuit to build strength endurance.

### 3) Rep length
10×400 → 10×500 in the same zone. Extends fatigue resistance, focus and ability to hold mechanics a little longer.

### 4) Terrain
Hills, soft (grass, sand, trail), hard (road, track), variable. Changes the stress biomechanically, neurally and psychologically. Hills shift muscle recruitment, and hard surfaces return elastic energy while soft surfaces absorb it. Treadmill vs outdoors is also a terrain choice (hybrid races are often indoors on hard floors with tight turns). Because it's zone-based, pace will naturally differ across terrain.

### 5) Volume
- **Total:** 5 km of work → 6 km. The global view of stress load.
- **Set volume:** 3 sets of 4×400 → 2 sets of 6×400. Same total, different impact.

### 6) Density
How much space is in the session. From 12×400 @ Z4 with 60 s rest:
- 3 sets of 4×400 with 3 min between sets, or
- 2 sets of 6×400 with 800 m relaxed tempo (Z2) in the set break.

### 7) "Stuff"
- **Aerobic / clearing:** a short segment to clear fatigue so more total work gets done, e.g. 6×100 m @ Z3 with turnaround rest.
- **Sprint:** hill sprints mid-session force fast-twitch recruitment, e.g. 2 sets of 4×800 @ Z4 with 5 short hill sprints @ Z5 between sets.
- **Strength:** a strength circuit instead of standing rest creates non-specific fatigue and specific strength endurance.

### 8) Surges *(race specific)*
Races are unevenly paced. Instead of even-effort 1 km reps @ Z3–Z4, surge 400–600 m within each rep to Z4–Z5, or have athletes surge 200 m on a signal.

### 9) Feedback & constraints *(race specific)*
Remove knowledge: no watch or splits, unknown rep count or rep length, "hold Z3 until I say stop", or effort-based with freedom to stop. Builds immunity to racing uncertainty.

## 3. Progression examples (extend vs qualify)

| Baseline | Extend | Qualify |
|---|---|---|
| 10×400 m @ Z4 / 90 s | 12×400, or 10×500 | 10×400 / 60 s rest, or faster logged splits in Z4 |
| 13 km long run @ RPE 5–6 (6–7 advanced) | 15 km | 13 km with 20 min @ Z3 in the middle |
| LT blocks: 20 min + 10 min @ Z3 / 2 min easy | 25 + 10 min, or 3×12 min | Same blocks with a 1 min break, or a Z2 float instead of easy jog |
| 4×1 km @ Z4 / 2 min | 5×1 km | 4×1 km with a 200 m surge to Z5 in each |
| VO2max 5×2 min @ Z4–5 / 60 s | 6×2 min, or 5×3 min | Faster logged output at the same zone |
| 8×1 km compromised (1 km + station) @ Z3–Z4 | 9 rounds | Same zone with a longer/heavier station, or faster logged run splits |

## 4. Frequency guide (from Step 5)

- **Short speed / hill sprints / strides:** frequent, small doses (neural, so lost quickly). Can be tacked onto easy runs.
- **Building a quality** (e.g. LT in base, race effort in specific): every ~7–14 days.
- **Maintaining a quality:** every ~14+ days.
- **VO2max:** focused blocks once LT and CV are established, not year-round. Monitor recovery.
- **Base phase:** mostly Easy (RPE 5–6) volume plus a long run (RPE 5–6; 6–7 advanced) + pure speed; LT emphasis; race-effort work every ~2 weeks.
- **Specific phase:** race-effort / compromised work up to weekly; high-end aerobic every ~2 weeks.

## 5. Running-specific notes for Claude

- Prescribe by **Zone + RPE** (with the feel descriptor). Never write fixed paces into a generic session; an athlete's own paces are only a logged or stored reference.
- The day after a medium–hard session or race is a **Z1 (RPE 1–4) recovery** session, not Z2. Warm-ups and cool-downs are RPE 1–4.
- Hill sprints inside a run are placed by time, e.g. "4×10 s hill sprints @ RPE 9.5–10 at the 20 min mark of the run, walk-down recovery".
- Progress one manipulator at a time; name it (e.g. "Qualify: recovery 90 → 75 s").
- Don't stack a "go to the well" run in the same 48 h as a hard station or heavy lower-body strength session.
- Pure speed: stop reps when mechanics break down. Threshold, interval and long sessions: productive fatigue is acceptable.
- Weekly structure changes add one stimulus at a time (e.g. 3 → 4 runs, extra run optional).
