# Cross-Training Workouts — Design Guide (Ergs, Low-Impact, Stations, Strength Endurance, Hybrid)

Read `00-training-zones.md` and `01-workout-design-principles.md` first. This file applies the same nine manipulators, the extend / qualify model and the **5-zone model** to non-running work: air bike, BikeErg, elliptical, SkiErg, rowing erg, pool/aqua running, sled push/pull, carries, lunges, wall balls, burpee broad jumps and other hybrid-race stations, plus strength-endurance circuits. Keep language general to "Hyathlon" hybrid racing, not one event brand.

**All intensities are Zone + RPE.** Use the **effort guide by modality** in `00` §5 to describe what each zone feels like on each machine; the percentages there are relative to the athlete's own threshold for that modality. Erg splits, watts and loads are athlete-specific and never written into a generic session. Loads are described by feel (e.g. "a load you can push 25 m at Z3") or as the race-standard weight for the athlete's division.

## 1. Session building blocks

The Magness session types carry over to cross-training (`00` §4–5):

| Session type | Zone (RPE) | Best modalities | Main pillar | Purpose |
|---|---|---|---|---|
| Recovery / absorption | Z1 (1–4) | Bike, elliptical, pool, easy row | Fatigue Management | Absorb hard sessions with no impact |
| Aerobic volume | Z2 Easy (5–6) or Steady (6–8), matching the run it replaces | Any erg, elliptical, pool | Aerobic Engine | Aerobic volume without running impact |
| Progression | Z1/Z2 → Z3 | SkiErg, row, bike | Aerobic Engine, Threshold | Broader fibre recruitment |
| Threshold blocks | Z3 (8–8.5) | Any erg; pool = zero-impact threshold | Threshold | Lactate clearance; e.g. 20 + 10 min blocks |
| Critical velocity | Z4 (8.5–9.5) | BikeErg, air bike, SkiErg, row | Threshold, Aerobic Engine | Fresh stimulus above threshold |
| VO2max intervals | upper Z4 – Z5 | Air bike, BikeErg, SkiErg | Aerobic Engine (ceiling) | 2–5 min reps, stationary rest ≈ half the work time |
| Sprint / power | Z5, full recovery | Air bike, BikeErg | Economy, Balanced Athleticism | Neural drive; ~1–2 min max, usually much shorter |
| Station technique / skill | Z1–Z2 | Stations | Economy | Efficient mechanics, pacing, transitions |
| Strength endurance circuits | Z2–Z4 | Stations, strength | Balanced Athleticism | Hold force output over many reps |
| Compromised / hybrid (run + station) | Z3–Z4 | Run + stations/ergs | Durability, Fatigue Management | Keep moving well when fatigued |
| Heavy / power strength | high effort, full rest | Strength | Balanced Athleticism | Force, resilience (neural; stop when form drops) |
| CrossFit-style WOD (For Time, AMRAP, EMOM; gymnastics, Olympic lifts, mixed modal) | Z3–Z5 | Barbell, gymnastics, ergs, stations | Balanced Athleticism, Fatigue Management | Mixed-modal capacity; a hard session (same consolidation rule as strength). CrossFit exercises come from the exercise database |

**Alternatives:** every cross-training session offers alternatives based on what the athlete has access to and prefers (e.g. "Pool run, or elliptical, or bike"). Athletes record their **available equipment and ranked modality preferences** at onboarding; list their preferred option first.

**Niggles and soreness: wait and watch, then act.**
- **Rated 3/10 or less:** wait and watch. No change to the plan; the athlete keeps reporting it. If it's getting worse: "if it persists or worsens, check with your medical professional".
- **Rated 4/10 or more, or reported as Pain (e.g. calf tightness):** make the affected sessions **fully off-feet** on their preferred modality, keeping the same session purpose and zone. Don't combine running and cross-training in the same session. If it persists or worsens: "check with your medical professional".

**Returning after a niggle: build back sensibly** (once it's back to 3/10 or less), never straight back to the previous level. Progression (adjust per athlete):
  - Week 1 back: easy runs only at RPE 5–6, about 50–75% of previous run duration. Other sessions stay off-feet. No hills, sprints or intensity.
  - Week 2: back towards normal run volume; reintroduce one key session if symptom-free.
  - If symptoms return at any step, go back a step. If it persists: "check with your medical professional".

Load-management options from the chart: **¾ slide on the rowing erg** when managing load; **pool running** as a genuinely zero-impact way to do threshold work.

## 2. Manipulators applied to cross-training

### 1) Speed / intensity
- **General increase:** raise the zone for the same work (e.g. 5×500 m row @ Z3 → @ Z4), or keep the zone and look for a faster logged split / higher watts / heavier logged load at that zone.
- **Within rep:** progressive or variable effort inside the rep. 1000 m SkiErg building Z2 → Z3 → Z4 → Z5 each 250 m; 20 wall balls as 10 @ Z3 + 10 @ Z4–5.

### 2) Recovery
- **Length:** long rest gives more power per rep (quality, anaerobic); short rest is more aerobic and works under incomplete recovery. VO2max reps: stationary rest ≈ half the work time (stop or sit still; easy spinning or rowing in the recovery makes it threshold work).
- **Style:** standing vs moving (walk, easy bike) vs an easy different station.
- **Speed of recovery:** easy row or bike @ Z1–Z2 instead of full rest.
- **"Stuff":** a run in the recovery (compromised running), a carry, a core/reactive mini-circuit, or a cognitive task to keep focus high.

### 3) Rep length / reps
Extend work in the same zone: 500 m row → 750 m; 50 m sandbag lunge → 75 m; 20 → 25 wall balls unbroken.

### 4) Terrain / environment / setup / modality
Change the stress biomechanically and psychologically:
- **Modality swap:** the same session on a different machine (e.g. threshold blocks on BikeErg instead of the run), or pool running for zero impact.
- **Station setup:** sled on a different surface (turf vs rubber changes friction), wall ball target height or ball weight, carry implement (kettlebells vs handles), fresh vs pre-fatigued grip.
- **Machine setup:** damper/resistance on ergs, ¾ slide on the rower.
- **Environment:** gym vs outdoors, working in a crowd or with noise.

The zone keeps the prescription valid across setups.

### 5) Volume
- **Total:** total reps, metres or time under work (e.g. 100 → 120 wall balls across the session; 30 → 40 min Z2 bike).
- **Set volume:** 4 sets of 25 wall balls vs 2 sets of 50 — same total, different impact; unbroken vs chunked strategies.

### 6) Density
Create or remove space. From 8 rounds of (500 m row + 20 wall balls) @ Z3–Z4 with 1 min rest:
- 2 sets of 4 rounds with 4 min between sets, or
- continuous rounds, with an easy 400 m jog (Z1–Z2) every 2 rounds as the "space".

### 7) "Stuff"
- **Aerobic / clearing:** insert easy erg or jog segments (Z1–Z2) so more total station work is achievable.
- **Sprint / power:** insert short explosive efforts @ Z5 (e.g. 3×10 s air bike sprint, 3 box jumps, short hill sprint) between sets for fast-twitch recruitment.
- **Strength:** heavy sled or carry (Z4) mid-session to create specific strength endurance and non-specific fatigue before running or stations.

### 8) Surges *(race specific)*
Hybrid races are uneven: congestion, burst efforts at the start of each station, fast finishes. E.g. 1000 m SkiErg @ Z3 with a 100 m surge to Z4–5 every 250 m; surge on a coach signal; finish the last station of a block @ Z5.

### 9) Feedback & constraints *(race specific)*
Hide the erg monitor, don't give the station order or round count, "hold Z3 until I say stop", unexpected station swaps. Prepares athletes for race-day uncertainty.

## 3. Progression examples (extend vs qualify)

| Baseline | Extend | Qualify |
|---|---|---|
| 5×500 m row @ Z3 / 1 min | 6×500 m, or 5×600 m | 45 s rest, or faster logged split in Z3 |
| BikeErg threshold 20 + 10 min @ Z3 | 25 + 10 min, or 3×12 min | 1 min break instead of 2, or higher logged watts in Z3 |
| Air bike VO2 4×3 min @ Z4–5 / 90 s | 5×3 min | Higher logged watts at the same zone |
| 4 rounds: 1 km run + 20 wall balls @ Z3–Z4 | 5 rounds, or 25 wall balls | Wall balls unbroken in the same zone, or rest cut |
| Sled push 4×25 m (Z3 load) / 2 min | 5×25 m, or 4×30 m | Heavier load at Z4, or 90 s rest, or a 200 m run in the recovery |
| Strength circuit 3 rounds @ Z3 / 2 min | 4 rounds | Same circuit, 1 min rest or a run between rounds |
| 30 min SkiErg @ Z2 | 40 min | Same time and zone with higher logged output |

## 4. Frequency & balance

- **Neural / heavy strength & power / sprints:** frequent exposure (quick to gain, quick to lose); stop sets when form drops.
- **Building a capacity (station, threshold erg, etc.):** repeat the stimulus every ~7–14 days.
- **Maintaining:** every ~14+ days.
- **VO2max erg blocks:** focused blocks, not year-round; monitor recovery.
- **Base phase:** Z1–Z2 erg volume, Z3 threshold blocks, technique and general strength; compromised sessions occasional.
- **Specific phase:** compromised / race-simulation work up to weekly; surges and constraints introduced.
- **Balanced Athleticism:** rotate stations and modalities across the block so no station, movement pattern or grip goes untrained; balance push/pull, upper/lower, bilateral/unilateral.

## 5. Cross-training notes for Claude

- Prescribe by **Zone + RPE**, and use the modality effort guide (`00` §5) for the feel on each machine. Never write fixed splits, watts or loads into a generic session. If athlete-specific zone values exist, show them alongside the zone.
- Offer adjustable sets (min / planned / max) so athletes can scale up or down on the day; the next block uses what they actually completed.
- Use Z1 cross-training (bike, elliptical, pool) as the default recovery option after hard runs or races, and for athletes managing impact load.
- State pillar, build/maintain and extend/qualify for every session, same as running.
- Pick exercises from the exercise database; don't invent stations.
- Account for interference with running: avoid heavy lower-body or high-volume lunge/sled work within ~24–48 h before a key run session.
- Count station and erg work in weekly load, not just running km.
- Coordinate with the strength coach's program: cross-training sessions complement, not duplicate, the strength plan.
- Strength and strength-endurance work follow `06-strength-principles.md`: working sets only, low volume/high effort, and only on hard days (never as light add-ons on recovery or easy days).
- **Ergs are modalities, not punishments:** frequency first (easy, often, technique), then volume, then intensity. The SkiErg costs more locally than heart rate suggests; the goal is an output fast, cheap and repeatable enough to run well afterwards (`09` §1).
- Productive fatigue applies to conditioning; for heavy/technical lifts, end the set when mechanics break down.
- Rehab or pain-related modifications: suggest considerations only, with "check with your medical professional".
